SinkPoint

방향성 중력과 그래플 이동을 중심으로 한 Unity 3D 액션 어드벤처입니다. Codex·Unity MCP와 함께 5일간 만들었습니다.

기간
2026.08.22 – 08.26 (5일)
형태
2인 Unity 프로젝트
엔진
Unity · C#
AI
Codex · Unity MCP
담당
Player · Camera · 전투 연동 · 방향성 중력 · 그래플 이동

시연 영상

중점 구현

  • 팀장이 잡은 MVP를 5일 일정에 맞춰 이동·전투·방향성 중력·그래플 범위로 구체화하고, 팀 씬 규칙에 따라 별도 Player Scene에서 구현 후 팀원 기능과 통합
  • SphereCastNonAlloc 카메라 가림 처리와 카메라 조준점 → 총구 2단계 Raycast 사격 판정 구현
  • 공용 GravityState의 PresentationUp을 Player·Camera가 함께 사용하도록 하여 방향성 중력·무중력 전환 시 이동 기준과 화면 Up을 맞춤
  • 일반·방향성 중력 보조 상승과 무중력 그래플의 상태·앵커·당김·LineRenderer 표현을 분리

AI 협업 방식

  • Unity MCP로 씬 복제·Prefab 생성·참조 연결·Play Mode 실행까지 AI에 맡기고, 중력 전환 오차·사격 Ray 정렬 같은 상태 값을 Play Mode 자동 확인으로 수치화
  • 전환 연출 시간·무중력 반작용 상한 같은 체감 값과 완료 판단은 직접 플레이로 정하고, MCP 작업 중 바뀐 ProjectSettings 값은 찾아 작업 전 값으로 복구
처음 써 본 Unity MCP, 범위부터 정했습니다

팀은 각자 자기 씬에서 작업하기로 정해 두어, AI 작업도 원본을 복제한 제 Player 씬으로 한정했습니다. 작업 기록은 항목마다 "Codex 사용처 / 사람이 직접 결정한 부분 / 검증 결과"로 나눠 남겼습니다. 완료 계획 22개.

난관과 해결: 방향성 중력에서 플레이어·카메라·물리 정렬

문제

중력이 바뀔 때 Player 이동·Rigidbody 정렬·VisualRoot 표현·Camera Up의 기준이 서로 달라졌습니다.

해결

방향·세기를 GravityState로 공유하고, PlayerController는 새 Gravity Up을 이동·접지 기준으로 쓰도록 역할을 나눴습니다.

결과

고정·주기·무중력 Preset 전환에서 Player·Camera·중력 반응 오브젝트의 기준을 통일하고, 컴파일·Inspector 참조·Play Mode·Console 상태를 함께 확인하는 검증 흐름을 썼습니다.
